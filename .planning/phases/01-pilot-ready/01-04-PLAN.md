| Boundary | Description |
|----------|-------------|
| Test process → app | Local TestClient invocations, no real network egress |
| Human operator → Twilio console | Manual upgrade + number provisioning; high-trust action requiring care |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-01-04-02 | Tampering | Operator skips updating `twilio_number` in `config/clients/allgreen.json` after Twilio provisioning, leaving the placeholder `+1XXXXXXXXXX` deployed | mitigate | Checklist has an explicit "verify routing" step that POSTs to `/twilio/voice` with the new number and expects 200; placeholder would yield 404. | T-01-04-03 | Repudiation | No record of who ran the upgrade or when | mitigate | Checklist has a "record date + operator" line at the bottom. Git commit of the filled-in checklist provides the audit trail |

    ```python
            "/twilio/voice",
    ```

    ### Reading minute usage from logs (COST-03)

    Per-call log line at session end:

    ```bash
    # Recent activity for a specific client
    fly logs --app clearslope-receptionist | grep 'session_finished' | grep 'client=allgreen'

        awk '{ for(i=1;i<=NF;i++) { if($i ~ /^client=/) c=$i; if($i ~ /^minutes_charged=/) m=$i } print c, m }' | \
        sort | uniq -c

    fly logs --app clearslope-receptionist | grep 'ceiling_hit'
    ```
