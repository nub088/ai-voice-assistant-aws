<objective>
Cut the voice path over to the registry. Three threads of work, all in two files:

1. **Routing.** `/twilio/voice` reads `To` from the Twilio form, looks up the `ClientContext` in `app.state.clients`, persists the `call_sid → to_number` bridge in `app.state.pending_calls`, and threads the per-client auth_token into signature validation.
2. **Ceiling guard.** Before returning the WebSocket TwiML, check `minute_counters[client_id]` against `client_ctx.config.minute_ceiling`. If at/over ceiling, return TwiML that plays the rejection message and hangs up, the Pipecat pipeline NEVER starts (D-09). Counter only increments at call end, so a graceful rejection costs zero minutes.
3. **Accounting.** `/twilio/stream` consumes the bridge entry, looks up the `ClientContext`, passes it (plus `minute_counters`) into `run_voice_session`. `run_voice_session` records `time.monotonic()` at start, in `finally` adds `math.ceil(elapsed_sec / 60)` to the per-client counter and emits a structured log line (D-10).

After this plan, both clients can take live calls; All Green will be capped at 200 minutes/restart.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Twilio webhook → app | Untrusted form data (`From`, `To`, `CallSid`); attacker-controlled if signature unset |
| Twilio Media Stream WS → app | Untrusted control frames; receives `streamSid` + `callSid` from caller-side bridge |
| In-process state mutation | minute_counters mutated from finally block; no lock needed (CPython dict mutation atomic for our usage; only one task per call_sid) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-03-01 | Spoofing | Forged Twilio webhook (no signature validation) | mitigate | `_validate_twilio_signature(request, form, auth_token)`, uses per-client auth_token from ClientContext (D-12). If auth_token is empty AND `ALLOW_UNSIGNED_TWILIO` is not enabled, raises 500. Validator rejects bad signatures with 403 |
| T-01-03-02 | Information Disclosure | Twilio To-number not in registry → request silently routes to wrong tenant or default | mitigate | Unknown `To` → HTTP 404 + `logger.error` with redacted To. Fail loud, no fallback to a default client |
| T-01-03-03 | Tampering | Minute ceiling bypass: counter not incremented on error paths | mitigate | Counter increment is in `finally:` block of run_voice_session, fires even when `runner.run(task)` raises. Verified by acceptance criterion: `try:` precedes minute timer init, `finally:` is present and contains `minute_counters[...]` assignment |
| T-01-03-04 | Tampering | Race condition: many concurrent calls past the ceiling all check counter ≈ ceiling-1 and start | accept | Pilot scale: ~46 calls/month after-hours = single-digit concurrent at peak. Cost of leaking 5 minutes past 200 ≈ $0.05; cost of adding lock = engineering time. Re-evaluate at scale |
| T-01-03-05 | Information Disclosure | pending_calls dict grows unbounded if WebSocket handshake never arrives | mitigate | pending_calls is `pop()`-ed in /twilio/stream (consumed once). Soft cap: if len(pending_calls) > 1000, log + trim to most-recent 500. Pilot volume makes leak negligible |
| T-01-03-06 | Repudiation | Per-client minute usage not auditable | mitigate | Structured `key=value` log emitted at every call end with `call_sid`, `elapsed_sec`, `minutes_charged`, `total_minutes`, `client=` (D-10). Plan 04 builds the verification grep |
| T-01-03-07 | Denial of Service | Caller spams a number with no client → repeated 404 logs flood | accept | Twilio rate-limits inbound; Fly handles burst. Punted to v2 if it becomes an issue |
| T-01-03-08 | Information Disclosure | Stream's customParameters could be tampered to spoof a different `From` | mitigate | Routing key is `To` (taken from /twilio/voice form, server-trusted because signature-validated), not `From`. customParameters only carries `from` for SMS confirmation, caller-controlled but only used as `to:` for the customer's own confirmation SMS, no privilege escalation possible |
</threat_model>

    ```python
        request: Request, form: dict[str, str], auth_token: str
    ) -> None:
        """Validate Twilio's `X-Twilio-Signature` header. `auth_token` is the
        per-client Twilio auth token from `ClientContext.auth_token` (D-12).
        For Phase 1 every client uses the same global token; the parameter is
        here now so subaccount support is a config change only."""
        if not auth_token:
            if os.environ.get("ALLOW_UNSIGNED_TWILIO", "").strip().lower() in {"1", "true", "yes"}:
                logger.warning(
                    "auth_token unset and ALLOW_UNSIGNED_TWILIO=1, skipping signature validation (dev only)"
                )
                return
            logger.error("auth_token required in production, rejecting request")
            raise HTTPException(
                status_code=500,

            )
        signature = request.headers.get("x-twilio-signature", "")
        url = str(request.url)
        validator = RequestValidator(auth_token)
    ```

    ```python
    @router.post("/twilio/voice")
    async def twilio_voice(request: Request) -> Response:
        """Inbound TwiML. Routes by `To` (D-01), enforces per-client ceiling
        BEFORE returning Stream TwiML (D-09), and bridges call_sid→to_number
        for /twilio/stream (D-03)."""
        form = dict(await request.form())

        to_number = form.get("To", "").strip()
        from_number = form.get("From", "").strip()
        call_sid = form.get("CallSid", "").strip()

        client_ctx = request.app.state.clients.get(to_number)
        if client_ctx is None:
            logger.error(
                "twilio_voice: unknown To number to=%s call_sid=%s registered=%s",
                _redact_phone(to_number),
                call_sid,
                sorted(request.app.state.clients.keys()),
            )
            raise HTTPException(status_code=404, detail="unknown destination number")

        # Validate signature using THIS client's auth_token (D-12).
        _validate_twilio_signature(request, form, client_ctx.auth_token)

        client_id = client_ctx.config.client_id

        # D-09: enforce ceiling BEFORE starting the pipeline. Counter increments
        # at call end (D-10), so a rejected call costs zero minutes.
        ceiling = client_ctx.config.minute_ceiling
        if ceiling is not None:
            used = request.app.state.minute_counters.get(client_id, 0.0)
            if used >= ceiling:
                logger.warning(
                    "ceiling_hit client=%s call_sid=%s minutes_used=%.0f minute_ceiling=%d action=reject",
                    client_id, call_sid, used, ceiling,
                )
                resp = VoiceResponse()
                resp.say(
                    "Our answering service is temporarily unavailable, "
                    "please call back during business hours."
                )
                resp.hangup()
                return Response(content=str(resp), media_type="application/xml")

        logger.info(
            "twilio_voice client=%s call_sid=%s to=%s from=%s minutes_used=%.0f minute_ceiling=%s",
            client_id,
            call_sid,
            _redact_phone(to_number),
            _redact_phone(from_number),
            request.app.state.minute_counters.get(client_id, 0.0),
            ceiling if ceiling is not None else "none",
        )

        # Bridge call_sid → to_number so /twilio/stream can recover the client
        # (websocket only sees streamSid + callSid in start event, not To).
        if call_sid:
            request.app.state.pending_calls[call_sid] = to_number
            # Soft cap against runaway memory if WS never connects.
            if len(request.app.state.pending_calls) > 1000:
                logger.warning(
                    "pending_calls exceeded 1000 entries, trimming to most-recent 500"
                )
                items = list(request.app.state.pending_calls.items())[-500:]
                request.app.state.pending_calls.clear()
                request.app.state.pending_calls.update(items)

        base = _public_base_url(request)
        response = VoiceResponse()
        connect = Connect()
        stream = Stream(url=f"{base}/twilio/stream")
        if from_number:
            stream.parameter(name="from", value=from_number)
        connect.append(stream)
        response.append(connect)
        return Response(content=str(response), media_type="application/xml")
    ```
