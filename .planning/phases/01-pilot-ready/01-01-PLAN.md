<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Filesystem → app | Per-client JSON files loaded at startup; malformed JSON crashes app at boot (acceptable, fail-fast) |
| Env vars → app | `{PREFIX}_*` env vars read by per-client factories in later plans; prefix collision could leak data across clients |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01-01 | Information Disclosure | env_prefix collision (e.g. ALLGREEN vs ALL_GREEN) | mitigate | env_prefix is loaded VERBATIM from JSON; prefix is uppercase + alphanumeric only; loader rejects empty or non-uppercase prefix with ValueError so a typo cannot silently fall back to a sibling tenant's vars |
| T-01-01-02 | Tampering | Malformed minute_ceiling value (string, negative, zero) | mitigate | Loader coerces minute_ceiling via `int(...)` only when present and not null; rejects values <= 0 with ValueError. Absent or null → None (no ceiling) |
| T-01-01-03 | Spoofing | Two client JSONs declaring the same twilio_number | mitigate | scan_client_configs raises ValueError when a duplicate twilio_number is encountered, duplicate routing key would silently overwrite a tenant otherwise |
| T-01-01-04 | Denial of Service | Dot-prefixed or hidden JSON file matched by glob | accept | sorted(glob("*.json")) skips dotfiles by default; explicit `*.json` glob only |
</threat_model>

       ```python
       twilio_number = str(raw["twilio_number"]).strip()
       if not twilio_number:
           raise ValueError(f"{path}: twilio_number must be non-empty E.164 string")

       env_prefix = str(raw["env_prefix"]).strip()
       if not env_prefix or not env_prefix.replace("_", "").isalnum() or env_prefix != env_prefix.upper():
           raise ValueError(f"{path}: env_prefix must be uppercase alphanumeric (got {env_prefix!r})")

       raw_ceiling = raw.get("minute_ceiling")
       if raw_ceiling is None:
           minute_ceiling = None
       else:
           try:
               minute_ceiling = int(raw_ceiling)
           except (TypeError, ValueError) as exc:
               raise ValueError(f"{path}: minute_ceiling must be int or null (got {raw_ceiling!r})") from exc
           if minute_ceiling <= 0:
               raise ValueError(f"{path}: minute_ceiling must be > 0 (got {minute_ceiling})")
       ```

    4. Add `scan_client_configs` function below `load_client_config`:
       ```python
       def scan_client_configs(config_dir: Path) -> dict[str, ClientConfig]:
           """Load every *.json in config_dir into a dict[twilio_number, ClientConfig].

           Raises ValueError on duplicate twilio_number across files (would cause
           silent tenant overwrite, fail loudly at startup instead).
           """
           result: dict[str, ClientConfig] = {}
           for path in sorted(config_dir.glob("*.json")):
               cfg = load_client_config(path)
               if cfg.twilio_number in result:
                   raise ValueError(
                       f"duplicate twilio_number {cfg.twilio_number} in {path} "
                       f"(already mapped to client_id={result[cfg.twilio_number].client_id})"
                   )
               result[cfg.twilio_number] = cfg
           return result
       ```
